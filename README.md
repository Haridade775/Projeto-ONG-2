# 🌍 Website Institucional ONG

<p align="center">
  <b>Um site institucional moderno, responsivo e focado no frontend, desenvolvido para apoiar as causas e projetos de uma Organização Não Governamental.</b>
</p>

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte do meu portfólio de desenvolvimento web. O objetivo principal é dar visibilidade às causas da ONG, facilitar a captação de voluntários e doadores, e apresentar informações organizadas sobre o impacto social gerado pela instituição.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do código.
- **CSS3:** Estilização responsiva, layout fluido e animações.
- **JavaScript (ES6+):** Interatividade, manipulação do DOM e validação de formulários.

## ✨ Funcionalidades
- **Design Responsivo:** Adaptado para celulares, tablets e computadores.
- **Navegação Intuitiva:** Seções dedicadas à história, projetos e métricas de impacto.
- **Formulário de Contato / Cadastro:** Interface pronta para captação de apoiadores e voluntários.
