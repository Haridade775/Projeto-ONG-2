## Objetivo
Site institucional e interativo em HTML5, CSS3 e JavaScript básico, sem frameworks e sem backend.

## Páginas
- `index.html` — Início
- `sobre.html` — História, missão, público e objetivos
- `projetos.html` — Três iniciativas (Castra Bairro, Feira Lar Doce Lar, Patinhas na Escola)
- `contato.html` — Formulário e orientações de voluntariado

## Funcionalidades JavaScript
1. **Formulário validado** (`js/formulario.js`): submit com addEventListener + preventDefault; trim(); nome ≥ 3, e-mail válido, assunto não vazio, mensagem ≥ 10; mensagem de erro/confirmação simulada no HTML.
2. **Mostrar/ocultar informações** (`js/script.js`, página Sobre): botão com addEventListener("click") alterna o painel e o texto do botão.

## Como executar
Abra a pasta no VS Code e abra `index.html` no navegador (ou use a extensão Live Server).
